Overview

This notebook explores the DataCo Smart Supply Chain dataset to understand demand patterns, shipping performance, and product category dynamics before building the forecasting model. Every finding below is computed from the warehouse built by scripts/setup_data.py.

Demand by Category

Code 
category_demand = q("""
    SELECT
        category_name,
        COUNT(*) AS order_lines,
        SUM(quantity) AS total_units,
        ROUND(SUM(revenue), 0) AS total_revenue,
        ROUND(AVG(unit_price), 2) AS avg_price
    FROM orders
    WHERE is_valid_demand
    GROUP BY category_name
    ORDER BY total_revenue DESC
    LIMIT 15
""")

fig = px.bar(
    category_demand,
    x="total_revenue",
    y="category_name",
    orientation="h",
    title="Revenue by Product Category (Top 15, excluding canceled/fraud)",
    labels={"total_revenue": "Total Revenue ($)", "category_name": "Category"},
)
fig.update_layout(yaxis=dict(autorange="reversed"), height=500)
fig.show()

A Structural Break in October 2017

Code 
monthly = q("""
    SELECT DATE_TRUNC('month', order_date) AS month,
           SUM(total_units) AS units,
           COUNT(DISTINCT category_name) FILTER (WHERE total_units > 0) AS active_categories
    FROM daily_demand
    GROUP BY 1 ORDER BY 1
""")
fig = px.line(monthly, x="month", y="units", title="Monthly Units Sold",
              labels={"month": "", "units": "Units"}, markers=True)
fig.add_vline(x=MODEL_END_DATE, line_dash="dot")
fig.show()

before = monthly[monthly["month"] < "2017-10-01"].tail(6)["units"].mean()
after = monthly[monthly["month"] >= "2017-11-01"]["units"].mean()
print(f"Average monthly units, 6 months before Oct 2017: {before:,.0f}")
print(f"Average monthly units, Nov 2017 – Jan 2018:      {after:,.0f} ({after / before - 1:+.0%})")
Average monthly units, 6 months before Oct 2017: 10,335
Average monthly units, Nov 2017 – Jan 2018:      2,008 (-81%)

After 2017-10-02 the catalog changes: most long-running categories stop and a handful of new ones appear, while total volume falls sharply. Forecasting models are therefore trained and evaluated only on data up to MODEL_END_DATE.

Is There Weekly Seasonality?

weekday = q(f"""
    SELECT EXTRACT(DOW FROM order_date) AS dow, AVG(units) AS avg_units

Late Delivery by Category

Code 
late_by_category = q("""
    SELECT category_name, COUNT(*) AS order_lines,
           ROUND(100.0 * AVG(late_delivery_risk), 1) AS late_pct
    FROM orders
    GROUP BY category_name
    HAVING COUNT(*) >= 1000
    ORDER BY late_pct DESC
""")
fig = px.bar(
    late_by_category, x="late_pct", y="category_name", orientation="h",
    title="Late Delivery Rate by Category (categories with 1,000+ order lines)",
    labels={"late_pct": "Late Delivery %", "category_name": "Category"},
    range_x=[0, 100],
)
fig.update_layout(yaxis=dict(autorange="reversed"), height=500)
fig.show()
print(f"Range across these categories: {late_by_category['late_pct'].min()}% – "
      f"{late_by_category['late_pct'].max()}%")

Do Lag Features Carry Signal?

Pooled across categories, lagged demand correlates strongly with today’s demand — but that mostly reflects categories having different levels. Within a single category, the question is whether yesterday or last week says anything about today.

Code 
corr = q(f"""
    SELECT
        CORR(lag_7d_units, total_units) AS pooled_lag7,
        (SELECT AVG(c) FROM (
            SELECT CORR(lag_7d_units, total_units) AS c
            FROM demand_features WHERE order_date <= '{MODEL_END_DATE}'
            GROUP BY category_name HAVING COUNT(*) >= 365)) AS within_category_lag7,
        (SELECT AVG(c) FROM (
            SELECT CORR(lag_1d_units, total_units) AS c
            FROM demand_features WHERE order_date <= '{MODEL_END_DATE}'
            GROUP BY category_name HAVING COUNT(*) >= 365)) AS within_category_lag1
    FROM demand_features
    WHERE order_date <= '{MODEL_END_DATE}'
""")
corr.round(3)
pooled_lag7 within_category_lag7 within_category_lag1
0 0.89 0.014 0.024

  1. Structural break: monthly volume changes -81% after October 2017 as the catalog changes, so models use data up to 2017-10-02 only.
  2. No weekly seasonality: the busiest and quietest weekdays differ by 2.2%.
  3. Late deliveries depend on shipping mode, not category: categories range only 54.5–57.0% late, while First Class is 95.3% late (planned 1.0 days, actual 2.0).
  4. Lags carry almost no within-category signal: lag-7 correlation is 0.89 pooled but 0.01 within a category.
  5. Discounts don’t move daily volume: average within-category correlation -0.04.
  6. Implication for forecasting: demand is close to noise around a stable level, so a tuned XGBoost model can at best match a 28-day moving average — which is what the holdout results show.
